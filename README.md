# KAIZE MM2 distribution

Upload `kaize_mm2.lua` to your GitHub repository. Replace YOUR_USERNAME and YOUR_REPO in `loader.lua` with your actual GitHub username and repository name. Share the loader line with customers.

**Security:** Obfuscation does not prevent extraction. Anyone who can run a client-side script can recover its source. The existing hardcoded key is also recoverable. For meaningful access control, validate licenses on a server you control, and never publish private secrets in client-side code. Keep the original source in a private repository.
